# TSX and JSX

BirJS uses Preact for TSX and JSX views. TypeScript projects use `.tsx` components and JavaScript projects use `.jsx` components.

Use `ctx.inertia()` with `views/pages/` for hydrated pages and client navigation. Use `ctx.render()` with named views for server-rendered HTML.

See [Views](/docs/views), [Components](/docs/components), and [Inertia](/docs/inertia) for setup and examples.
