Core Architecture

Controllers & Resources

Instead of defining all request handling logic in route closures, controllers organize behavior into dedicated classes.

Generating Controllers

Use the bir CLI to scaffold a new controller:

bir make:controller PostController

Writing Controller Actions

Controllers receive the active Context instance: 

import type { Context } from 'birframework';
import { User } from '../models/User.js';

export class UserController {
  async index(ctx: Context) {
    const users = await User.all();
    return ctx.json({ users });
  }

  async show(ctx: Context) {
    const user = await User.find(Number(ctx.params.id));
    if (!user) {
      return ctx.json({ error: 'User not found' }, 404);
    }
    return ctx.json({ user });
  }
}

Resource Routes

Register RESTful routes (index, show, store, update, destroy) with a single declaration: 

import { Route } from 'birframework';
import { PostController } from '../app/controllers/PostController.js';

Route.resource('/posts', new PostController());
