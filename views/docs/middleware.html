Core Architecture

Middleware Pipeline

Middlewares inspect and filter incoming HTTP requests before reaching route handlers.

Defining a Middleware

Middlewares receive the Context and a next() callback: 

import type { Context, Middleware } from 'birframework';

export const authGuard: Middleware = async (ctx, next) => {
  const token = ctx.headers['authorization'];
  if (!token) {
    return ctx.json({ error: 'Unauthorized' }, 401);
  }
  await next();
};

Applying Middleware to Routes

Attach middlewares to individual routes or route groups: 

// On a single route
Route.get('/admin', (ctx) => ctx.json({ admin: true }))
  .middleware(authGuard);

// On an entire group
Route.group({ prefix: '/api', middleware: [authGuard] }, () => {
  Route.get('/secret', (ctx) => ctx.json({ access: 'granted' }));
});
