Database & ORM

Migrations & Seeders

Version control your database schema across team members with typed migrations.

Creating a Migration

bir make:migration create_posts_table

Migration Structure

Migrations use the fluent Schema blueprint builder: 

import { Schema, type Blueprint } from 'birframework';

export async function up() {
  await Schema.create('posts', (table: Blueprint) => {
    table.id();
    table.string('title');
    table.text('content');
    table.integer('user_id');
    table.timestamps();
  });
}

export async function down() {
  await Schema.dropIfExists('posts');
}

Executing Migrations

# Run all pending migrations

bir migrate

# Roll back the latest migration batch

bir migrate:rollback
