Task Scheduler (Cron)

Define scheduled background tasks fluently in code without configuring operating system crontab entries.

Defining Schedules

import { Schedule } from 'birframework';

// Run every minute
Schedule.call(async () => {
  console.log('Running health check ping...');
}).everyMinute().name('health-ping');

// Run daily at midnight
Schedule.call(async () => {
  await cleanupExpiredSessions();
}).dailyAt('00:00').name('session-cleanup');

// Run hourly
Schedule.call(async () => {
  await syncAnalytics();
}).hourly();

Running the Scheduler Daemon

# Start background scheduler daemon

bir schedule:work

# Or execute due tasks once (for CI / system crontabs)

bir schedule:run
