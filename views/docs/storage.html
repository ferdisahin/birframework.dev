File Storage & Mail

Unified file disk abstraction and mailable classes with testing driver fakes.

Storage Manager

Read, write, and check file existence with the Storage facade: 

import { Storage } from 'birframework';

// Save file to local disk
await Storage.disk('local').put('invoices/inv_101.pdf', pdfBuffer);

// Check if file exists
if (await Storage.disk('local').exists('invoices/inv_101.pdf')) {
  const content = await Storage.disk('local').get('invoices/inv_101.pdf');
}

// Delete file
await Storage.disk('local').delete('invoices/inv_101.pdf');

Sending Mail & Testing Fakes

import { Mail } from 'birframework';

// Send raw HTML email
await Mail.to('alex@example.com').raw('<h1>Invoice Ready</h1>', 'Monthly Invoice');

// Testing fake in unit tests
const mailFake = Mail.fake();
// ... run application code ...
assert.strictEqual(mailFake.sent.length, 1);
assert.strictEqual(mailFake.sent[0].to, 'alex@example.com');
