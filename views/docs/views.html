Frontend & Views

Blade Component Engine

BirFramework includes a zero-dependency template compiler featuring Laravel Blade-style syntax, component tags, and named slots.

Component Tags & Slots

Wrap pages in layouts using component tags like <x-layouts.app>: 

<!-- views/users/show.html -->
<x-layouts.app title="User Profile">
  <div class="container">
    <h1>{{ user.name }}</h1>
    <p>{{ user.email }}</p>
  </div>

  <x-slot name="sidebar">
    <p>Profile navigation links</p>
  </x-slot>
</x-layouts.app>

Control Structures

Iterate over arrays and render conditional content: 

@if(user.isAdmin)
  <span class="badge">Administrator</span>
@endif

<ul>
  @foreach(item in items)
    <li>{{ item.title }} - #{{ item.id }}</li>
  @endforeach
</ul>

Escaping & Raw Output

Interpolation {{ data }} automatically escapes HTML for XSS prevention. Use {!! rawHtml !!} when rendering trusted HTML or pagination links.
