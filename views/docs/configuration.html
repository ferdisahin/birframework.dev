Getting Started

Configuration & Environment

BirFramework includes a zero-dependency environment variable parser that loads .env files automatically into process.env on boot.

The .env File

Create a .env file in your project root to configure your application port, environment, and database:

# Server Settings

APP_ENV=local

PORT=3000

APP_KEY=your-32-character-secret-key

# Database Connection (sqlite | postgres | mysql)

DB_CONNECTION=sqlite

DB_DATABASE=storage/database.sqlite

# Production PostgreSQL Example

# DB_CONNECTION=postgres

# DB_URL=postgres://user:password@localhost:5432/myapp

Smart Port Fallback

If the port specified in PORT is already occupied by another service on your machine, BirFramework automatically detects EADDRINUSE and increments to the next available port (3001, 3002...) without crashing your process.
