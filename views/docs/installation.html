Getting Started

Installation

Get up and running with a new BirFramework application in seconds using the interactive project initializer.

System Requirements

  • Node.js: Version 20.0.0 or higher (Node 22+ recommended for native SQLite).
  • Package Manager: npm (v9+), pnpm, or yarn.
  • Operating System: macOS, Linux, or Windows WSL2.

Creating a Project

Run the official installer using npx:

npx birframework new my-app
npx birframework new my-app

The CLI prompts you interactively for your language and styling preferences:

? Select language:

1) TypeScript (Default, Recommended - Strict End-to-End Types)

2) JavaScript (Pure ESM)

? Select styling:

1) Tailwind CSS (Default, Utility-First)

2) Pure CSS (Vanilla CSS without build step)

Automated / CI Setup

You can pass explicit flags to skip interactive prompts in CI/CD pipelines or scripts:

# TypeScript with Tailwind CSS (Default)

npx birframework new my-app --ts --tailwind

# Pure JavaScript with Pure CSS

npx birframework new my-app --js --css

Starting the Development Server

Navigate to your new project directory and start the hot-reload dev server:

cd my-app

npm install

npm run dev

Your server is now running at http://localhost:3000.
