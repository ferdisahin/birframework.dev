CLI Command Reference

BirFramework includes the bir binary to handle scaffolding, migrations, workers, and server management.

Command Description
bir new <name> Scaffold a new project with interactive prompts.
bir serve Start the development server with file watching and auto-reload.
bir route:list Display all registered routes in a formatted table.
bir make:controller <Name> Generate a new Controller class in app/controllers.
bir make:middleware <Name> Generate a new Middleware function in app/middlewares.
bir make:model <Name> [-m] Generate an Active Record Model (and optional migration).
bir make:migration <name> Generate a new timestamped schema migration file.
bir make:job <Name> Generate a background Job class in app/jobs.
bir auth:scaffold Scaffold complete authentication (controller, model, views, migration).
bir migrate Execute all outstanding database migrations.
bir migrate:rollback Roll back the most recent batch of database migrations.
bir queue:work Start the asynchronous queue worker process.
bir schedule:work Start the in-process cron task scheduler daemon.
