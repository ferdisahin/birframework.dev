Directory Structure

BirFramework organizes application files following clean, predictable MVC conventions. 

my-app/
├── app/
│   ├── controllers/     # HTTP Controllers handling request logic
│   ├── models/          # Active Record ORM database models
│   ├── middlewares/     # Request interceptor pipelines
│   └── jobs/            # Background queue jobs
├── database/
│   ├── migrations/      # Schema migration files
│   └── seeders/         # Database seeders
├── public/              # Static web assets (CSS, JS, images)
│   └── css/app.css
├── routes/
│   └── web.ts           # HTTP route definitions
├── views/
│   ├── layouts/         # Blade master layouts (<x-layouts.app>)
│   └── welcome.html     # Blade view templates
├── app.ts               # Main application entry point
├── package.json
└── tsconfig.json
