Core Architecture

Routing & Parameters

BirFramework provides a fast, expressive routing system inspired by Laravel's fluent route definitions.

Basic Routes

Routes are defined in routes/web.ts using the fluent Route facade: 

import { Route, type Context } from 'birframework';

// Basic GET route returning JSON
Route.get('/status', (ctx: Context) => {
  return ctx.json({ status: 'ok', uptime: process.uptime() });
});

// POST route reading request body
Route.post('/submit', async (ctx: Context) => {
  const body = await ctx.body();
  return ctx.json({ received: body }, 201);
});

// Supported HTTP verbs: Route.get, Route.post, Route.put, Route.patch, Route.delete

Route Parameters

Capture dynamic URI segments using either :id or {id} syntax: 

Route.get('/users/:id', (ctx: Context) => {
  const userId = ctx.params.id;
  const page = ctx.query.page || 1;
  return ctx.json({ userId, page });
});

Route Groups

Group routes with shared URL prefixes and middleware stacks: 

Route.group({ prefix: '/api/v1', middleware: ['auth'] }, () => {
  Route.get('/profile', (ctx) => ctx.json({ user: ctx.session?.get('user') }));
  Route.post('/billing', (ctx) => ctx.json({ status: 'billed' }));
});

Real-Time & LLM Token Streaming

Stream live events or LLM tokens directly using native Server-Sent Events (SSE): 

Route.get('/ai/generate', (ctx: Context) => {
  return ctx.stream(async (send) => {
    send('data: {"token": "Hello"}\n\n');
    send('data: {"token": "BirFramework"}\n\n');
  });
});
