Database & ORM

Active Record Models & Queries

BirFramework includes an Eloquent-style Active Record implementation with Proxy attribute access, relationships, and fluent querying.

Defining Models

Extend the Model class: 

import { Model } from 'birframework';

export class Post extends Model {
  static override table = 'posts';
  static override primaryKey = 'id';

  // Belongs-to relationship
  user() {
    return this.belongsTo('users', 'user_id');
  }
}

CRUD & Query Builder

// 1. Create a record
const post = await Post.create({
  title: 'Introducing BirFramework',
  user_id: 1,
  status: 'published'
});

// 2. Retrieve records with chaining
const posts = await Post.where('status', '=', 'published')
  .orderBy('created_at', 'desc')
  .get();

// 3. Find by ID
const single = await Post.find(1);

// 4. Update
await single.update({ title: 'Updated Title' });

// 5. Pagination
const paginated = await Post.paginate({ page: 1, perPage: 15 });

ACID Transactions

Execute operations within an atomic transaction. If an error is thrown, the transaction is automatically rolled back: 

import { DB } from 'birframework';

await DB.transaction(async (trx) => {
  await trx.table('accounts').where('id', 1).decrement('balance', 100);
  await trx.table('accounts').where('id', 2).increment('balance', 100);
});
