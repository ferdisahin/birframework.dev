Database & ORM

Multi-Driver Database Layer

BirFramework supports SQLite, PostgreSQL, and MySQL through an abstract database connection manager.

Supported Drivers

1. Native SQLite (node:sqlite)

Node.js 22+ comes with built-in SQLite support. BirFramework uses native node:sqlite with zero npm compilation or native binary bindings.

2. PostgreSQL

Translates positional parameters (?) automatically into PostgreSQL parameter markers ($1, $2) and supports connection string URLs.

3. MySQL / MariaDB

Supports standard MySQL parameter bindings and schema dialect.
