BirFramework includes secure Scrypt password hashing, HMAC-SHA256 signed session cookies, CSRF protection, and authentication guards.

Generate complete login and registration views, controllers, models, and migrations in one command:

Using Auth & Hash Services

import { Auth, Hash } from 'birframework';

// Hash a password securely with Scrypt
const hashed = await Hash.make('secret123');

// Authenticate user credentials
Route.post('/login', async (ctx) => {
  const { email, password } = await ctx.body();
  const authenticated = await Auth.attempt(ctx, { email, password });

  if (!authenticated) {
    return ctx.json({ error: 'Invalid credentials' }, 401);
  }

  return ctx.json({ message: 'Login successful' });
});
