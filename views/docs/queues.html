Services & Workers

Queues & Background Jobs

Offload time-consuming tasks like sending emails or processing uploads to asynchronous background queues.

Creating a Job Class

bir make:job ProcessPaymentJob 
import { Job, dispatch } from 'birframework';

export class ProcessPaymentJob extends Job {
  constructor(public amount: number, public customerId: string) {
    super();
  }

  async handle() {
    // Perform payment gateway API calls
    console.log(`Processing payment of $${this.amount}`);
  }
}

// Dispatch to queue
await dispatch(new ProcessPaymentJob(150, 'cust_992'));

Running the Queue Worker

Start the worker daemon to continuously process jobs from the queue:

bir queue:work --queue=default
