Core Architecture

Request Validation

Validate and sanitize incoming request data with declarative rules directly on the HTTP context.

Using ctx.validate()

Call ctx.validate(rules) to enforce constraints. If validation fails, BirFramework automatically sends an RFC-compliant 422 Unprocessable Entity response with field-level errors: 

Route.post('/register', async (ctx) => {
  const data = await ctx.validate({
    name: 'required|string|min:2',
    email: 'required|email',
    password: 'required|min:8|confirmed',
    role: 'in:admin,member'
  });

  return ctx.json({ success: true, user: data }, 201);
});

Supported Validation Rules

Rule Description
required Field must be present and not empty.
email Field must be a valid email address format.
min:value String length or numeric value must be at least value.
max:value String length or numeric value must be at most value.
confirmed Field must match [field]_confirmation.
in:foo,bar Value must be one of the specified options.
