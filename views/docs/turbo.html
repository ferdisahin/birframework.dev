Instant Turbo Navigation

BirFramework provides single-page application (SPA) navigation speed directly over server-rendered Blade templates using a lightweight client morphing engine.

How It Works

When a user clicks a regular HTML link (<a href="/posts">), BirTurbo intercepts the navigation, fetches the page in the background, morphs the incoming DOM elements smoothly into place, updates the browser history URL with pushState, and displays a subtle top progress bar.

There are zero page flushes, zero white screens between transitions, and no client-side JavaScript framework is needed.

Enabling BirTurbo

Add the directive {!! bir_scripts() !!} right before the closing </body> tag in your master layout: 

<!DOCTYPE html>
<html>
<head>
  <title>{{ title }}</title>
</head>
<body>
  {!! slot !!}

  <!-- Injects lightweight client-side Turbo morphing script (~2.5 KB) -->
  {!! bir_scripts() !!}
</body>
</html>
